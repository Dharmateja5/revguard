Execution-focused build plan with gates and exit criteria

1. Build Strategy

Rule: complete P0 before spending meaningful time on P1 conversational evidence.

4. Definition of Done — P0

  • At least one successful recovery case, one No Action case, and one HITL case work end-to-end.
  • All critical adversarial tests pass.
  • Financial outputs are deterministic and reproducible.
  • Duplicate/unknown execution behavior is verified.
  • Every outcome produces an auditable trace.
  • Demo can run from a clean environment with known test data.

5. Scope Control

Do not add live writes, live telephony, extra agent frameworks, A2A, GraphRAG, production Kubernetes, or enterprise IAM unless P0 and demo are already complete.
