Supplier Exception Resolution
05 — Implementation Plan

Three-Week Implementation Plan

Week 1 — Data & Deterministic Core

  • Define 12–15 benchmark cases and ground truth first.
  • Create synthetic POs, suppliers, inventory, demand, commitments, freight options, approvals.
  • Create supplier email/messages for each scenario.
  • Implement Pydantic schemas and case state.
  • Implement shortage/coverage engine.
  • Implement sourcing/spend/material policy engine.
  • Implement mock enterprise stores and read/write APIs.
  • Implement audit/event log and idempotency.
Week 1 exit: every benchmark can be solved manually by deterministic reference logic and policy checks.

Week 2 — Agentic Layer

  • FastMCP tool server.
  • Jev routing and typed tool calling.
  • Nemotron coordinator with bounded loop.
  • Evidence collection and state updates.
  • Recovery alternative generation.
  • HITL handoff object.
  • Sandbox execution and post-action verification.
  • Retry / unknown-execution handling.
Week 2 exit: end-to-end case resolves from supplier message to verified sandbox outcome.

Week 3 — Evaluation & Portfolio

  • Run benchmark suite and log trajectories.
  • Add adversarial cases.
  • Measure tool accuracy, policy compliance, action validity, latency/cost.
  • Build compact investigation UI.
  • Show evidence, current state, alternatives, policy result, execution, verification.
  • Create architecture diagram, README, demo script, and 3-minute video.
  • Polish one spectacular scenario and one failure/HITL scenario.

Build Order

Benchmark → Data → Deterministic Core → MCP → Jev → Nemotron Loop
→ HITL → Execution → Verification → Evaluation → UI → Demo
