Demo & Submission

Three-minute story, screens, and fallback plan

1. Demo Goal

Show one memorable investigation that proves both agentic capability and safe financial control.

Core story: RevGuard appears ready to recover an expired concession, then discovers contradictory evidence in a recorded customer call and correctly blocks automatic action.

2. Three-Minute Script

TimeWhat to ShowMessage
0:00–0:20Problem screen: expired 15% concession; billing still applies itPotential revenue leakage exists, but root cause is not yet known.
0:20–0:55Jev route + Coordinator launching evidence retrievalRevGuard chooses an investigation path and queries enterprise systems through typed tools.
0:55–1:20Contract + billing + CRM evidenceEverything currently points toward recovery.
1:20–1:45Recorded call found; play a short clip; show diarized transcriptA commercial conversation introduces conflicting evidence.
1:45–2:15Evidence verification + source authority panelThe statement is real, but commercial authority is unresolved.
2:15–2:35Deterministic financial calculation and policy resultRevGuard calculates exposure exactly but blocks auto-recovery.
2:35–2:50HITL packageHuman reviewer receives the claim, evidence, rejected alternatives, and financial impact.
2:50–3:00Architecture summary“Agents investigate. Deterministic systems authorize.”

3. Demo Data

  • Contract/amendment showing concession expiration.
  • Invoice lines showing continued discount.
  • CRM/approval record with no formal extension.
  • One pre-recorded synthetic call containing a verbal extension.

4. What Judges Should Notice

  • Multi-step autonomous investigation, not a single prompt.
  • Heterogeneous evidence across structured data, documents, and conversation.
  • NVIDIA technology is functionally relevant, not decorative.
  • Financial action is separated from probabilistic reasoning.
  • The system handles ambiguity by stopping safely rather than hallucinating certainty.

5. Backup Demo

Keep one voice-free P0 case ready. If P1 fails during recording or judging, the core RevGuard workflow must still demonstrate investigation, verification, deterministic finance, policy, and HITL/recovery.
