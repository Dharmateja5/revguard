Supplier Exception Resolution
03 — Architecture

System Architecture

Architecture thesis: Agents investigate and adapt. Jev structures decisions and tool calls. Deterministic systems validate, authorize, execute, and verify.

Agentic Components

  • Investigation Coordinator: owns case state, chooses next step, enforces budgets and termination.
  • Supply Analysis capability: reasons about supplier commitments, alternates, and sourcing evidence.
  • Logistics capability: reasons about expedite / split-shipment options and timing.
  • Recovery Planner: synthesizes valid alternatives and recommends next action.

P0 can implement these as capabilities under one coordinator rather than separate processes to avoid needless multi-agent overhead.

Jev Roles

  • Classify exception type and urgency.
  • Route deterministic vs agentic vs HITL path.
  • Generate typed tool selections and arguments.
  • Structure next-action decisions.
  • Validate enum/date/identifier constraints before tool execution.

Trust Boundaries

  • LLM output is advisory until structured and validated.
  • Jev structures tool intent but does not authorize writes.
  • Deterministic policy engine owns authorization.
  • Sandbox execution requires idempotency key.
  • Verification is mandatory after each write.
