Scope

Autonomous Revenue Leakage Investigation & Recovery
Architecture thesis: Agents investigate. Deterministic systems verify, calculate, authorize, and execute.

Objective

Build a bounded agentic system that investigates potential B2B revenue leakage across heterogeneous enterprise evidence, determines the supported root cause, calculates financial impact deterministically, and routes the case to recovery, no action, or human review.

Core Workflow

Trigger → Jev Routing → Agentic Investigation → MCP Evidence Retrieval
→ Evidence Verification → Source Authority → Financial Engine
→ Policy / Authorization → HITL or Sandbox Recovery → Verification & Audit

P0 — Core MVP

  • Investigation Coordinator + Contract, Billing, and Recovery Recommendation agents
  • Jev structured routing with generative fallback
  • Typed MCP tools for Contract, Usage, Billing, CRM, and Recovery
  • Durable investigation state, budgets, and explicit termination states
  • Evidence provenance, verification, sufficiency, and source authority
  • Deterministic finance; context-aware policy/authorization; HITL
  • Recovery state machine, idempotency, reconciliation, audit
  • Ground-truth evaluation and adversarial failure tests

P1 — Showcase Extension

  • 1–3 synthetic pre-recorded commercial calls
  • ASR + Nemotron diarization
  • Timestamped speaker-attributed transcript evidence
  • Participant-role mapping from controlled metadata
  • Conversational evidence treated as evidence, not authority
  • Lightweight tracing / observability

Gate: P1 begins only after P0 end-to-end and critical failure tests pass.

Technical Boundaries

LLMs: hypotheses & reasoningJev: structured routingMCP: controlled accessPydantic: typed boundariesDeterministic financeLeast privilegeHITL for ambiguity

No probabilistic component may directly create an unauthorized financial effect.

Demo Scenario

An expired concession appears to create revenue leakage. Contract and billing support recovery, but RevGuard discovers a recorded call where an account manager verbally extends the discount. The statement is verified as conversational evidence, yet formal commercial authority is missing. RevGuard calculates exposure deterministically, blocks automatic recovery, and routes the case to HITL.

Out of Scope

Live production writes, live telephony, speaker biometrics, autonomous customer calling, FX/multi-currency, large agent swarms, A2A, GraphRAG/knowledge graphs, production-scale concurrency, Kubernetes/Kafka, and full enterprise IAM.
